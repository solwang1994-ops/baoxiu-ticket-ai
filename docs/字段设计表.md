# 售后报修工单字段设计表

## 表名：tickets
工单核心信息表，存储所有报修工单的完整字段。

## 字段明细
| 字段名 | 数据类型 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- |
| id | INTEGER | 自动生成 | 主键，自增，唯一标识每条工单 |
| ticket_no | TEXT | 是 | 工单编号，全局唯一，不可重复 |
| customer | TEXT | 是 | 客户名称/报修单位 |
| phone | TEXT | 是 | 联系电话 |
| device_type | TEXT | 是 | 设备类型，如工业缝纫机、空压机、电梯等 |
| device_sn | TEXT | 是 | 设备编号/机身序列号 |
| fault | TEXT | 是 | 故障现象描述 |
| report_date | TEXT | 否 | 报修日期，未填默认取当日日期 |
| priority | TEXT | 否 | 优先级，可选：低/普通/高/紧急，默认普通 |
| status | TEXT | 否 | 工单状态，可选：待处理/处理中/已完成/已关闭，默认待处理 |
| note | TEXT | 否 | 备注信息 |
| created_at | TEXT | 自动生成 | 工单创建时间，录入时自动写入 |

## 设计原则
1.  必填字段与 CLI 录入、Web 表单保持口径完全一致
2.  所有文本字段统一存储为字符串，兼容 SQLite 存储特性
3.  状态、优先级为枚举值，后续可扩展规则分类与统计
4.  工单号设唯一约束，从数据库层面杜绝重复录入
