# 售后报修工单智能助手（P-TICKET）

本项目是一个基于 Flask + SQLite 构建的轻量级售后报修工单管理系统，支持工单录入、智能分类、多维筛选以及数据导出，并接入了 AI 大模型实现故障自动分级。

## 一、核心功能

1. **新建工单**：通过 Web 页面录入设备故障信息，支持自动防重复拦截与落库。
2. **台账查询与筛选**：支持按设备编号、工单状态（待处理/已处理等）进行实时动态筛选。
3. **数据导出（CSV）**：一键导出工单台账，采用 `utf-8-sig` 编码，确保 Excel 打开中文不乱码。
4. **AI 智能分类**：接入 DeepSeek API，根据故障描述自动推荐故障分类与维修建议；在网络异常时无缝降级为本地规则匹配。

## 三、运行与验收指南

### 1. 启动服务

在命令行中运行以下命令启动 Web 服务：

```bash
python src/app.py

```

服务启动后，默认运行在 `http://127.0.0.1:5000`。

### 2. 功能验收步骤

#### ① 验证新建工单

1. 浏览器访问 `http://127.0.0.1:5000/` 打开录单页。
2. 填写工单信息并点击"提交工单"。
3. 页面提示提交成功，且数据已持久化写入 `data/tickets.db`。

#### ② 验证状态筛选

1. 访问台账列表页 `http://127.0.0.1:5000/list`。
2. 使用页面顶部的"状态"下拉框（如：全部、待处理、已处理）进行筛选。
3. 确认列表数据能够根据所选状态进行实时、准确的过滤。

#### ③ 验证导出 CSV

1. 在台账列表页，点击"导出 CSV"按钮。
2. 浏览器自动下载 `.csv` 数据文件。
3. 双击使用 Excel 打开，确认所有这个文件我是有的，但是不是放在根目录下面中文字段（如客户姓名、故障描述）均显示正常，无乱码。

## 四、技术栈

- **后端框架**：Flask
- **数据库**：SQLite（本地文件型，无需额外安装数据库服务）
- **AI 大模型**：DeepSeek API（可选，未配置时自动降级为本地规则分类）
- **前端**：原生 HTML + JavaScript（Flask 模板渲染）

---

## 五、已知限制

- 单机演示版：SQLite 本地文件存储，适合个人作品/面试演示；多用户并发场景需迁移至服务端数据库。
- 规则分类的关键词基于通用工业售后经验编写，实际落地时需根据行业特点调整 `rules.json`。
- AI 分类依赖 DeepSeek 网络与额度；默认超时 15 秒并自动降级，业务不中断。
- 未做登录鉴权，仅限本地 `127.0.0.1` 演示使用。
